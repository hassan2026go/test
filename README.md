# 🌳 شجرة العشيرة - منصة التوثيق والتعداد العائلي

منصة ويب حديثة (PWA) مخصصة لتوثيق أنساب العشيرة، تتبع الأجيال، وإدارة البيانات العائلية بواجهة عربية أنيقة وسريعة. تعمل المنصة بكفاءة على الهواتف المحمولة وأجهزة الكمبيوتر، وتدعم العمل دون اتصال بالإنترنت.

## ✨ المميزات الرئيسية

*   **شجرة تفاعلية:** عرض الأنساب برسم بياني (SVG) مع إمكانية التكبير والتصغير.
*   **خريطة عائلية:** فرز تلقائي للأفراد حسب المدن وتوزيعهم على خريطة تفاعلية.
*   **نظام إدارة:** لوحة تحكم للمدير (إضافة/تعديل/حذف)، ونظام مراجعة للأسماء الجديدة.
*   **تواصل متكامل:** رسائل واقتراحات (مع إمكانية رد الإدارة) وغرفة دردشة نصية فورية.
*   **تصدير واستيراد:** تصدير البيانات كملف `Excel (CSV)`، أو `PDF`، أو نسخة احتياطية `JSON`.
*   **تخصيص كامل:** إمكانية تغيير شعار المنصة، ألوانها، ونصوصها الترحيبية من لوحة الإدارة.

## 🛠️ التقنيات المستخدمة

*   **الواجهة الأمامية:** HTML5, CSS3, Vanilla JavaScript.
*   **الخريطة:** مكتبة Leaflet (مفتوحة المصدر) مع OpenStreetMap.
*   **قاعدة البيانات والمصادقة:** Supabase (سحابي).
*   **الاستضافة:** GitHub Pages.
